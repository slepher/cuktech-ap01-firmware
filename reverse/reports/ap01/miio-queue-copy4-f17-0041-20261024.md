## 真正新增

证据类型为旧dossier必要assembly和原厂字节独立位域核对；以下是n=4的静态条件代入，不是执行/模拟指令，也不是原源码：

|地址|必要选择/数据语义|
|---|---|
|`0xa000589c/589e/58a0`|a5=7，a6=入口dst，a4=dst+n；均只在寄存器内保存/计算。a0仍为入口dst|
|`0xa00058a4`|unsigned BLTU a5,a2→0xa000592c仅在7<n成立。n=4不成立，不进旧大长度对齐循环|
|`0xa00058a8/58aa`|a4=4；BEQ n,a4→0xa000591c，n=4选择此边，不沿其他长度分支取证|
|`0xa000591c/591e`|a5=dst；CJ→0xa00058f6，进入4B序列|
|`0xa00058f6/58fa`|按既有规则读U8(src+0)到a4，a1增1；写U8(dst+0)，a5增1|
|`0xa00058fe/5902`|同样读/写offset1，再各增1；不是先读完整4B快照|
|`0xa0005906/590a`|同样读/写offset2，再各增1|
|`0xa000590e/5912`|普通LBU a4,0(a1)，SB a4,0(a5)，此时两基址为原src+3/dst+3；无后续增量|
|`0xa0005916`|JR ra返回，路线没有写a0，故返回原dst；没有JAL/callback/分配/释放或栈store|

必要伪代码，**非原源码**，保留交错访问与4次byte写，不作任意域替代实现：

```c
// 仅n=4及本题正常有效、word对齐等前提。
original_dst = a0;
srcp = a1;
dstp = a0;
b = load_u8(srcp); srcp += 1;
store_u8(dstp, b); dstp += 1;
b = load_u8(srcp); srcp += 1;
store_u8(dstp, b); dstp += 1;
b = load_u8(srcp); srcp += 1;
store_u8(dstp, b); dstp += 1;
store_u8(dstp, load_u8(srcp));
return original_dst;
```

在正常复制前提下，dst获得源4B值；这里只证明实际逐byte顺序，不认证并发/原子快照、任意重叠或异常地址行为。指针参数只在寄存器中作为地址运算，没有直接写入其他持有对象或callee，不需要helper返回之后仍借用原source以继续读。若4B载荷本身是I指针的值，复制该值不意味着retain I、深拷贝I或负责I的生命周期；M/queue/consumer的持有另按原F11合同。

新增是 **n4这个有限输入域的分支/byte顺序/返回/无直接参数持有合同**；旧1080B代码发现0、旧业务功能0、ISA/来源认证与整库排除0。不是新增helper或完整memcpy恢复。
