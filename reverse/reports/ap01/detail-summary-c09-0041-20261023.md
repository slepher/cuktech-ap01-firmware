// 只表示 a00dcf30..a00dcf51；对象 NULL 的入口断言分支不在此伪代码内。
Object *child_nonnull_local(Object *obj, int32_t index) {

## 与总信息 callback 的已证关系

`a00f3952` 的 gate 和 change_mask 门控沿用已有消费者报告。局部调用窗口确认：`a00f3a1e` 设 tag=`0x0d`（十进制13），`a00f3a2e` 调 `a00a72ae(root,tag,&page,&ctx)`；返回非零、page 非零、ctx 非零时，`a00f3a3e` 跳 `a00f3aee` 的日志段。随后 `a00f3b08` 将输出 ctx 装入 a0，`a00f3b0c` 直接调用 `a00f3844`，`a00f3b10` 回后续 mask 检查段。
