## 观察到的路径

| 命令与条件 | 用例数 | 保留回放观察 |
| --- | ---: | --- |
| `0x52`，len=0 且 payload=NULL | 1 | 抵达 `0xa00a8626` 的首次 payload 读取前停止 |
| `0x52`，payload 非空，len=0 或 1 | 2 | 均抵达接口查找 `0xa00a53c0`，在入口停止 |
| `0x56`，len=12 | 1 | 返回，不调用 memcpy |
| `0x56`，len=13，接口 0 存在 | 2 | 内容相同则不复制；内容改变则复制 12 B 到 `0x62fd1018` 后返回 |
| `0x56`，len=13，接口 1 越过夹具中的单接口范围 | 2 | 相同的零内容不复制；改变内容时向地址 0 复制 12 B，随后抵达 `0xa00a9d18` |
| `0x56`，len=13，上下文为空且内容改变 | 1 | 向地址 0 复制 12 B，随后抵达 `0xa00a9d18` |
| `0xd1/0x55/0x57/0x58/0x5e`，len=0 且 payload=NULL | 5 | 抵达 memcmp 入口，NULL 源参数与固定长度分别为 7/24/6/4/3 B；执行比较前停止 |

总计 14 组。`0x56` 各例的 memcmp/memcpy 执行原厂指令；日志、通知和调度调用用被动夹具跳过。其他列出的停止点之后没有继续执行。

固定长度 helper 将应答描述符 `+4` 的 payload 指针作为源，按调用者给定的长度比较；内容不同时按相同长度复制，再通过当前回调发送 `cmd+0x20` 通知。该局部 helper 未使用描述符中的应答长度限制比较或复制。五组空 payload 用例证明调用能抵达 NULL 参数的固定长度 memcmp 入口，不能描述成已经完成了 NULL 读取或复制。

`0x56` 的两组异常目的地址用例进一步收窄了旧报告中显式零地址读取路径的到达条件：在本夹具的接口查找失败或上下文为空、12 B 内容不同时，先完成目的地址为 0 的复制，再抵达 `0xa00a9d18`。若内容相同则可能没有复制，不能省略这个分支条件。

## 解释边界与下一步

回放显式提供可读写零页、合成上下文与 payload；设备的零页映射、异常处理及后续结果仍未知。不能把夹具中向地址 0 的复制称作已观察到实机崩溃、任意代码执行或外部可利用漏洞。普通应答函数仍有坏指令控制流及不可达块警告，局部回放不能消除整函数的分析限制。

上一轮[接收长度报告](uart-retry-receive-0041-20261023.md)证明接收器在特定合成状态下会把长度 0 的应答以 NULL payload 派发；本轮从普通应答入口单独开始，尚未把接收解析器与本回调连接为端到端回放。真实活动命令、回调所有权、重入及销毁时序也未闭合。

下一步应连接接收解析器与普通应答回调，保留 CRC、活动命令及回调状态前置条件；再补接口查找失败后的完整生命周期与异常处理证据。本轮没有修改原件、候选 ROM 或设备状态。
