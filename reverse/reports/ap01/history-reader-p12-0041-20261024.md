## 真正新增：可用于重建的接缝合同

以下是分析伪代码，不是原源码。M/c是通知时重读的 borrowed item字段；p是该页面保存的byte cursor。

```c
// 已通过 app/page/selected-port 门；P与I是不同对象。
if (u32(I+0) & 0x400) {
    if (u16(I+0x1a4) == 0) {
        api_a0090470(ptr(P+0x3c),ptr(P+0x40),1);
        hide(ptr(P+0x44),1); store32(P+0x4c,0);
        show(ptr(P+0x64),1);
        // 此分支没有同步 P+0x60，也不逐点补零。
    } else {
        uint8_t c = u8(I+0x1a6);
        hide(ptr(P+0x64),1);
        api_a0090470(ptr(P+0x3c),ptr(P+0x40),0);
        show(ptr(P+0x44),1);
        uint8_t p = u8(P+0x60);
        if (p < c) for (unsigned k=p; k<c; ++k) emit(k);
        else if (c < p) {
            for (unsigned k=p; k<180; ++k) emit(k);
            for (unsigned k=0; k<c; ++k) emit(k);
        }
        store8(P+0x60,c); // c==p时也写；但不emit
    }
}
void emit(unsigned k) {
    uint32_t value = u16(I+0x3c+2*k);
    store32(P+0x4c, chart_glue_a00a64e4(value,P+0x3c));
}
```

增量顺序是从 **旧页面cursor（含）到新item cursor（不含）**；回绕先尾再头。writer以old_slot写样本，正常返回后cursor指向下一槽，因此完成后的增量读取序列接上；不证明发布/并发原子性。原物理store顺序是先写next到cursor，再写samples[old_slot]，必要时再将cursor回绕写0，不能由old_slot概念重排。`c==p` 不提交任何点，无法识别整180次或更多写入；不通知/门控不满足/页面不匹配时也不会追cursor。本轮不推断页面首次cursor、跨item复用如何复位，不能由本增量路径保证首次显示180点或无丢样。

`0x400` 是本分支的更新门，不在callback内清除；通知器后续清mask沿P-R02既有合同。maximum=0走可见性/复位分支，而非一般增量循环：不应自行把它“修正”为消费cursor或写180个零。其他普通数值分支照旧执行，不在本题重导。

### 图表胶水和停止边界

`0xa00a64e4(value,C)` 的 C为 **P+0x3c**，其中 `+0 chart* / +4 series* / +8 marker* / +0x10 cached_max / +0x14,+0x18 point输出`。`P+0x4c` 正好是 `C+0x10`，不是另一个独立历史副本。

胶水先无符号比较 cached_max与value；value较大才写cached_max并调用 `0xa019c5d0(chart,0,value)`。随后 `0xa00925e0(chart,series,value)` 按值接收当前点；`0xa0093a7c(chart,series,179,C+0x14)` 取末点坐标；`0xa00dbb68(marker,chart,1,x-8,y-7)` 移动标记，最后返回当前cached_max。C+0x14的输出指针保存于栈中跨第一次API调用后恢复；不是把item借给公共库。

这些调用形状分别支持“设置图范围 / 追加值 / 读点位置 / 对齐对象”的静态推断，可映射到公开LVGL图表/对象API作为重建方案；本轮不认证原库精确版本、公开函数符号或具体chart update mode。到此停止，不展开LVGL绘图、formatter或存储内部。`0xa0090470(chart,series,0/1)` 保留原调用边界，不凭常量猜完整公共API名。

**寿命已证范围**：reader同步从 borrowed I加载u16，胶水只接收value标量与页面C；它没有接收I或ring地址，也未把它们写入页面/库参数。页面保留byte cursor、cached_max和图表对象/series，point输出落页面本身。item不必为这条点提交额外retain；callback返回后的item可用性沿生产/通知合同，不能保留其指针。**未知范围**：公共chart库内部如何复制/滚动数据、分配失败行为、series释放及页面最终销毁；没有从本轮静态胶水推出库不分配或完整对象安全。重建可选自有series并按值复制，属于策略，不是原ROM源码认证。
