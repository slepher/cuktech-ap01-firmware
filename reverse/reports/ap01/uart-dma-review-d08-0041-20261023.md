## 可读数据/状态与所有权

以下是分析表达，不是原源码或可编译参考实现；L/S注明宽度，每次访问保留原重读意义。

```c
Transfer { u32 src, dst, nbytes; };        // start栈上，每项12B
Lli      { u32 src, dst, next, control; }; // 固定RAM，每项16B
// control count[11:0], SWidth[19:18], SI26, DI27, I31
// pool: type<=1 ? 62fc86e4+64*type : 62fc85fc；capacity=4
// lengths: 62fc86d0/86d8+4*type；phase:u8@62fc86e0+type
// type>1: lengths62fc85f0/85f4；phase:u8@62fc85f8

start(d) {
    cfg=copy20(a01bb000); tr[0]={L32(d+78),dst,L32(d+80)};
    tr[1]={L32(d+7c),dst,L32(d+84)};
    // 原channel sign8/0..2及n1非0门；type2配置/dst查询保留相对ops ABI。
    S32(d+88,0); clear(reloaded_channel);
    save_lengths_by_reloaded_type(); S8(phase,0);
    // type<=1另先置UART regs+80 bit0
    configure(handle_reloaded,&cfg); txint(d,0);
    install(handle_reloaded,a0019d9a,d); clear(reloaded_channel); mask(reloaded_channel);
    submit(reloaded_channel,pool_for_reloaded_type,tr,L32(d+84)==0?1:2);
    enable(reloaded_channel);             // 没有检查submit a0
}
build_width0(regs,pool,4,tr,count) {
    used=0;
    do {                                 // 原序为先体后count比较
        len=L32(tr+8); n=len/4064+1; last=len%4064;
        if(n!=1 && last<=30) { --n; last+=4064; }
        first=pool+16*used; src=L32(tr); dst=L32(tr+4);
        ctrl=(L32(regs+12)&0x7ffff000)|4064;
        for(j=0;j<n;j++) {
            p=first+16*j;
            S32(p,src); S32(p+4,dst); S32(p+8,0);
            if(ctrl&(1<<26))src+=4064;
            if(ctrl&(1<<27))dst+=4064;
            if(j==n-1)ctrl=(ctrl&0x7ffff000)|((last|0x80000000)&0x80000fff);
            if(j)S32(p-8,p); S32(p+12,ctrl);
        }
        if(not_first_transfer)S32(first-8,first);
        used+=n; if((u32)used>4)goto epilogue;
        tr+=12;
    }while(more_transfer);
    S32(regs,L32(pool)); S32(regs+4,L32(pool+4));
    S32(regs+8,L32(pool+8)); S32(regs+12,L32(pool+12));
    clean(pool,used*16);                   // a0最终保留pool+used*16
epilogue: return a0_residue;              // 未显式赋used_count/errno
}
```

上面数学写法是原寄存器运算的可读表达；原逐指令读取见JSON。每个 transfer 末项置I=1，中间LLI清I；双段中第一段末项仍置I，故不能把“只有链最后一项才有I”套到本 ROM。默认byte配置且每段≤1024B时，各段n=1，正常1/2 transfer只用1/2个LLI；1024B cap来自D06已核设备初值，并不是 builder 对所有调用者的输入保证。

生命周期：源frame→设备ring的同步复制由D04继承；本题tr仅借用ring地址，builder在返回前消费tr并写固定pool。栈地址不逃逸，而LLI.src/channel.src保存ring地址值；payload没有被搬到pool。持久length/phase在submit之前发布，正常callback靠dev/type/channel查这些值，未依赖栈/LLI指针。phase1中途返回不归还tail；终结stop/clear后发布consumed→release，软件tail归还后下一次start可重写固定pool。此处“可重写”是本次软件流程的顺序，不证明全局pool互斥或close后所有权。

release的资源语义是软件ring槽归还，不是heap free或UART最后一byte物理发完。hardware enable bit、phase、dev两段长度、持久两长度各自独立，不能归为单busy字段。
