## Reproduction

From Linux/WSL, run `python3 -B tooling/scripts/test-native-wifi-switch-0041.py --app-repo <codex_status> --out <precreated-output>` for the production core and adapter with ASan/UBSan. Build/audit/link from the main integration entrypoints; ROM packaging remains firmware-owned.

Run `verify-native-wifi-menu-qemu.py --runner <codex_status>/tools/run-ap01-native-qemu.py ... --lvgl-input-model --fb-ready-api-model --animation-wexti-model --wifi-driver-model` with the exact candidate/manifest/NOR/profile arguments recorded in `artifacts/ap01-wifi-completion-20261022/nav04.command.json`. This executes real original LVGL focus/events/rendering and guest VFS/PSM; driver replies are explicit synthetic RF fixtures. `--wifi-restart --resume-native-report <nav04.json>` reuses that run's verified NOR without reseeding cache/list/credentials. Restart scanning uses an explicit finite1s empty-radio fixture, retaining the64-scan safety bound. The LCD screendump remains a logo in this virtual model: use original LVGL `.fb0.rgb565` snapshots, not that LCD image, for visual acceptance.
