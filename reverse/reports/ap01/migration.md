# 文件位置整理

当前目录与用途以[仓库入口](../../../README.md)为准。报告集中于 `reverse/reports/ap01/`，现用工具位于 `tooling/scripts/`，可交叉编译的实验模块位于 `tooling/firmware-modules/`。

历史迁移清单位于 `reverse/migration/`，停用的迁移、文档同步及业务尺寸探针已集中到其 `scripts/` 子目录，见[归档说明](../../migration/README.md)。冻结清单中的旧绝对路径只代表当时来源，不能用作当前运行入口。

原始日志、反汇编、JSON 和哈希保持原样；现用文档和工具使用当前目录。私有运行材料不随 Git 分发，缺失项须另行准备，不据历史清单声称已经存在。
