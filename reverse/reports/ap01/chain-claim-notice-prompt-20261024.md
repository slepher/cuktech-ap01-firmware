# 逆向流程更新通知与半小时任务模板

更新：2026-10-25。供后续已获授权的研究派发使用。保存本文不代表已通知其他聊天，也不启动或恢复研究；现有运行状态及静态限制保持；后续按授权采用三席执行加一席预调研，本文不自行启动该席位。完整规则见[统一流程](reverse-design.md)，唯一认领位置见[管理记录](rolling-management-0041-20261023.md#链条认领表)。任务派发即授权独占分支本地提交，交付 commit 后由主树验收合并；此规则覆盖旧模板中的“不提交/提交另行授权”，推送仍须单独授权。

## 发给管理窗口的通知

后续 AP01 逆向采用以下新规则，替代旧的跨题复用上下文、逐字段派发与复核，以及可替代库内部的默认深挖要求：

1. **新任务独立上下文。** 新研究任务和新复核批次都新建代理，显式 `fork_turns: "none"`。不继承完整主聊天，不把长期代理换题当作新任务。仅同一任务的澄清、补证、交付修正可继续当前代理；换接口/模块或新半小时工作块时落盘简短交接并新建。
2. **最小交接。** 给目标、认领行、原件身份与基线、必要锚点、独占输出、已有结论/差集和必要证据绝对路径/JSON pointer。不粘贴整段管理历史或工具大输出；只读统一流程、当前规则、自己的认领行及相关证据，不默认通读历史。
3. **约半小时切块。** 每块按单代理约30分钟有效工作量估算，20–40分钟作规划参考，含定位、分析、必要静态检查和简洁交付；非作者复核另计。小差集合入同接口，过大则按可独立验收的状态机阶段拆分。到预算仍未闭就保存部分结果、阻塞与剩余估算，不到点标完成，不自动无界续作。
4. **完整接口交付。** 以输入/提交→持有/状态→结果/失败/超时→取消/关闭/归还为目标，不按单字段、copy长度或helper交付。阶段交付明确共享合同及接口尚缺部分；全部必要阶段完成后才能标接口闭合。
5. **一次登记有限依赖。** 管理窗口先按地址/对象/问题查重并登记接口起止、对象、允许依赖和排除项。边界内且无冲突的必要callee/字段可同题完成，不逐项回报申请；跨接口/所有权、冲突或超静态范围时才报锚点、差集及必要增量，登记后再展开。同链同题仅一位作者，已验部分直接继承。
6. **公共库优先替代。** 有功能等价的开源实现即可停止追原内部，不要求精确匹配原ROM版本。formatter/copy、GUI/cache、通用事件循环、JSON/TLS、解码器等不作为默认后继。登记上游/API、错误/所有权约束、适配与未验证项；只有继续调用原二进制所需ABI、具体厂商差异或替代缺必要能力时才局部研究。原来源未知仍未知，替代可用不等于已移植；专有协议、无线闭源边界和MCU不得随之误排除。
7. **合并非作者复核。** 同接口的字段/helper/连续阶段小差集合批，新复核代理使用 `fork_turns: "none"`，且对整批均未参与作者工作；否则分批。按接口验收表核跨阶段对象、ABI、状态、所有权及错误/超时/取消/关闭，不重复全历史。底座、存储、OTA/启动等关键边界继续独立审查。修正只复核必要差集。
8. **精简交付与批次核算。** 一个接口报告汇总继承、纠正、新增和断边；主窗口每批统一整合更新。记录估计/实际时间、工具等待/中断和可获得的token用量；没有数据就写不可得，不推算成实测。衡量闭合接口或可用阶段，不以报告/文件/检查数衡量进度。
9. **提交、合并与转存后收尾。** 独占worktree/输出，不撤销他人修改，不改共享表、不自行接题或创建下级代理。保留当前禁止目标执行、设备/外部服务、生产/ROM/配置/分析器修改、构建/SIM/QEMU/历史回放及推送的静态限制。派发即授权研究者/复核者在独占分支本地提交报告、必要合同/清单及复验源码，交付分支/基线/commit SHA，由主树验收后合并，不以口头指导或手工复制代替提交整合。中间产物不入commit，由管理窗口转存至主树相同相对路径并确认被忽略；先复制核对，再移除任务树副本，同名异内容不覆盖。任务停止、commit全部合并、tracked/untracked干净且ignored产物全部转存核对后，按统一流程第7节核对绝对路径，无force移除worktree，再用 `git branch -d` 删除对应分支；受阻则保留，不丢弃研究记录或产物。

10. **专门预调研与动态预分配。** 三席研究/复核之外另设一席`task_prep_research_两位序号`，新建独立上下文，提前维持3份可直接派发的同接口任务包。它负责查重、材料可用性、真实差集、有限依赖及阶段/实测估时，不抢做研究、不写共享认领表、不自行派发。主窗口收到任务结束消息后，把结果、实际耗时/等待、token与断边通知它；主窗口只核最新冲突和依赖、登记并派发已备包，预调研代理同步补齐队列，并据当前进度及最近同类实测合并/拆分下一包。20–40分钟是实质工作包目标，预算不能当预测；缺材料或只剩短差集不凑满3份。具体独立上下文、生命周期、提交与技术非作者要求见统一流程3.3节。

不要为更新流程重建历史账本、重做既有逆向或恢复已停止任务。待后续获得研究授权，再按下方模板派发。

## 预调研代理与完成通知模板

```text
新代理名：task_prep_research_两位递增序号；fork_turns: "none"。
职责：一个补位批次/接口域的任务预调研；执行三席之外单独一席，不自行派生代理。
执行席位数 / 可派包目标数：3 / 3；不足如实说明，不凑微任务。
当前管理基线 / 认领表定位 / 优先接口 / 已验与待交付依赖：
独占worktree / 分支 / 队列报告与analysis路径：
每包：优先级、可派/待消歧/缺材料、候选名/认领建议、完整接口问题、已有覆盖/真实差集、
      原件/基线、必要VA/对象与证据绝对路径、起止/依赖/排除项、验收及最小派发文本、
      组成阶段/分别估时/近期可比实测/置信度、独占输出建议。
完成通知输入：认领ID、结论、产物/commit、开始/结束/墙钟、等待/中断、实际token（cached单列）、
              未闭边/新种子、当前执行席位及已从队列取走的包。
收到通知后：更新覆盖/依赖和优先级，按实际差集动态合并/拆分下一包，补足目标可派数量。
主窗口：只做最新冲突/依赖/授权核对、唯一认领登记与实际派发，负责验收合并转存。
交付：精简队列定位/变动/不足原因及commit，遵守统一流程3.3及第7节；不改共享表。
限制：静态范围不变；不把预调研当已验，不深挖公共库/无种子边，不复用旧上下文跨域换题。
```

## 研究任务派发模板

```text
新代理名：领域_research_两位序号；既有名称保留，同题修正不更名。
认领ID / 接口或独立阶段：
目标及业务用途：
原件身份引用 / 研究基线 / 主仓库绝对路径：
已恢复结论 / 既有复核 / 本次精确差集：
必要入口、对象、callsite/callback / 证据绝对路径与JSON pointer：
起止事件 / 允许的有限依赖 / 相交认领与分界 / 排除项：
开源替代判断：选用候选与API；若必须研究原内部，列具体理由和停止条件。
验收：输入输出、状态、错误/超时、取消/关闭、持有/归还；阶段交付列剩余共享合同。
组成阶段与分别估时 / 类比本批实测 / 已定位证据及未知依赖 / 置信度：
工作包目标：约30分钟（参考20–40）；实际预计墙钟：___，不能直接抄目标预算。
短于20分钟的同接口增量先合并，只有短差集就标短项并入既有任务/复核，不独立再开完整链。
独占worktree / 分支 / 报告与analysis输出：
本地提交授权：本次派发即授权在上述独占分支按精确路径提交本任务报告、必要合同/清单和复验源码，无需另行申请；不授权推送。
上下文：新建代理，fork_turns: "none"；仅提供本任务最小交接包。
协作：并非独自工作，不撤销他人修改；只修改独占文件，不写共享认领表。
限制：只做已授权静态研究；不自行派生代理/接后继/推送或扩到排除范围；中间产物不强制加入Git。
交付：先本地提交，再回报分支、启动基线、commit SHA、工作树状态及待转存中间产物清单；由主树验收合并。
收尾：管理窗口将中间产物转存到主树相同相对路径，核对完整性及忽略状态后移除源副本；确认任务树干净、ignored无遗留、commit已合并，再无force清理worktree及用branch -d删除分支。
回报：接口/阶段闭合或部分状态、可用结论、产物路径、实际检查、精确断边；
      估计/实际墙钟时间及等待/中断，可获得的token用量（不可得须注明）。
到预算仍未闭：保存已证事实、阻塞/新种子与剩余估算，回管理窗口决定后继。
```

## 合并复核派发模板

```text
新代理名：领域_review_两位序号；同领域/类型序号递增，列全部对应认领ID。
复核批次 / 原认领ID集合 / 作者列表：
复核者对整批均为非作者；新建代理，fork_turns: "none"。
接口摘要 / 阶段交接合同 / 本批差集 / 必要已验前提：
各差集报告与证据绝对路径、JSON pointer / 独占复核输出：
独占worktree / 分支 / 启动基线：
本地提交授权：本次派发即授权在独占分支提交复核报告、必要合同/清单和复验源码，不授权推送。
交付与收尾：交付commit SHA及待转存中间产物清单，由主树验收合并；管理窗口按统一流程第7节转存核对中间产物，确认任务树干净、ignored无遗留后清理worktree及已合并分支。
接口验收表：正常输入到结果、对象身份、ABI/宽度、状态、所有权、错误/超时/取消/关闭。
按本批类似差集实测单独预测墙钟与置信度（可以6–10分钟）；不统一填30分钟。
大批参考20–40分钟，过大按接口或独立阶段分批，不按字段拆复核。
只复核本批必要差集；不重做整库/全历史，不用管理整合代替技术验收。
逐项接受/纠正/未决；阶段已验与完整接口闭合分列，关键断边不得批量盖过。
修正后仅复查必要差集；记录实际时长、等待/中断及可获得的token用量。
协作、独占范围和静态限制与原研究一致；不改作者成果或共享认领表。
```
