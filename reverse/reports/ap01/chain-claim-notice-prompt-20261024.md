## 发给管理窗口的通知

后续 AP01 逆向采用以下新规则，替代旧的跨题复用上下文、逐字段派发与复核，以及可替代库内部的默认深挖要求：

1. **新任务独立上下文。** 新研究任务和新复核批次都新建代理，显式 `fork_turns: "none"`。不继承完整主聊天，不把长期代理换题当作新任务。仅同一任务的澄清、补证、交付修正可继续当前代理；换接口/模块或新半小时工作块时落盘简短交接并新建。
2. **最小交接。** 给目标、认领行、原件身份与基线、必要锚点、独占输出、已有结论/差集和必要证据绝对路径/JSON pointer。不粘贴整段管理历史或工具大输出；只读统一流程、当前规则、自己的认领行及相关证据，不默认通读历史。
3. **工作量准入。** 常规研究包同时满足完整可用阶段及据近期实测预测20–40分钟真实未闭工作量；扣除已验覆盖、已定位材料、现成工具和公共API止边。连续只用几分钟时必须合并同接口实际范围，不能只把标签改为3–8分钟继续独立派发。不足20分钟且无相关阶段可并的列短尾，纳入原任务补充或相关合批复核，不逐段另起作者→复核链；缺少合格包如实说明。超过40分钟按可验收阶段拆分；到预算未闭保存部分结果，提前完成立即交付，不等待凑时长。
4. **完整接口交付。** 以输入/提交→持有/状态→结果/失败/超时→取消/关闭/归还为目标，不按单字段、copy长度或helper交付。阶段交付明确共享合同及接口尚缺部分；全部必要阶段完成后才能标接口闭合。
5. **一次登记有限依赖。** 主窗口先按地址/对象/问题查重并决定接口起止、对象、允许依赖和排除项，由唯一主树写入者登记，回传认领行与基线后才派发。边界内无冲突的必要callee/字段可同题完成；跨接口/所有权、冲突或超静态范围时才报锚点及必要增量，登记后展开。同链同题仅一位作者，已验部分直接继承。
6. **公共库优先替代。** 有功能等价的开源实现即可停止追原内部，不要求精确匹配原ROM版本。formatter/copy、GUI/cache、通用事件循环、JSON/TLS、解码器等不作为默认后继。登记上游/API、错误/所有权约束、适配与未验证项；只有继续调用原二进制所需ABI、具体厂商差异或替代缺必要能力时才局部研究。原来源未知仍未知，替代可用不等于已移植；专有协议、无线闭源边界和MCU不得随之误排除。
7. **合并非作者复核。** 同接口的字段/helper/连续阶段小差集合批，新复核代理使用 `fork_turns: "none"`，且对整批均未参与作者工作；否则分批。按接口验收表核跨阶段对象、ABI、状态、所有权及错误/超时/取消/关闭，不重复全历史。底座、存储、OTA/启动等关键边界继续独立审查。修正只复核必要差集。
8. **精简交付与真实计时。** 一个接口报告汇总继承、纠正、新增和断边；交付立即进入整合队列，不因补位而延后。执行代理首个工具调用记录UTC开始，技术冻结、提交完成和停止分列；正常工具时间计入墙钟，排队/中断另列。没有完整起点只报可观测区间；token不可得就注明。研究与复核分别校准，不以报告/文件/检查数衡量进度。
9. **提交、合并与转存后收尾。** 独占worktree/输出，不撤销他人修改，不改共享表、不自行接题或创建下级代理。保留当前禁止目标执行、设备/外部服务、生产/ROM/配置/分析器修改、构建/SIM/QEMU/历史回放及推送的静态限制。派发即授权研究者/复核者在独占分支本地提交报告、必要合同/清单及复验源码，交付分支/基线/commit SHA，由主树验收后合并，不以口头指导或手工复制代替提交整合。中间产物不入commit，由整合席（未启用时主窗口兼任）转存至主树相同相对路径并确认被忽略；先复制核对，再移除任务树副本，同名异内容不覆盖。任务停止、commit全部合并、tracked/untracked干净且ignored产物全部转存核对后，按统一流程第7节核对绝对路径，无force移除worktree，再用 `git branch -d` 删除对应分支；受阻则保留，不丢弃研究记录或产物。

10. **专门预调研与动态预分配。** 三执行之外设一席`task_prep_research_两位序号`，独立上下文，保持执行中任务之外的3份真实可派库存。分别列常规研究可派、合批复核可派、短尾待合并、条件模板、待消歧、缺材料；仅前两类计可派，分别报告数量，短复核不冒充半小时研究。作者在跑时提前落盘条件复核模板及包ID/定位，待最终commit、停止及差集确认后转可派。预调研不抢做取证、不写共享表、不派发；完成消息同时送预调研校准补包、整合席接收交付。主窗口核边界/依赖/授权和实量准入，经唯一写入者登记确认后派发。库存不足如实报告，不凑微任务。见统一流程3.2–3.3节。

11. **专职整合与单写入者。** `task_integration_两位序号`独立上下文，实际负责主树范围/引用检查、合并、ignored转存核对、清理及状态登记，不替代非作者技术验收。接管前交接HEAD、全部未提交与ignored保留事项、认领表、运行状态、交付SHA和阻塞；接管后主窗口及其他聊天不并发写主树。积压增长先恢复整合能力，不靠继续派研究堆积任务树。运行、技术验收、整合三种状态分列；已交付未合并称整合待办，中断且有未提交成果不能当已交付。完整职责及收尾条件见统一流程3.4和第7节。

不要为更新流程重建历史账本、重做既有逆向或恢复已停止任务。待后续获得研究授权，再按下方模板派发。

## 预调研代理与完成通知模板

```text
新代理名：task_prep_research_两位递增序号；fork_turns: "none"。
职责：一个补位批次/接口域的任务预调研；三执行及一整合之外单独一席，不自行派生代理。
执行席位数 / 可派包目标数：3 / 3；不足如实说明，不凑微任务。
当前管理基线 / 认领表定位 / 优先接口 / 已验与待交付依赖：
独占worktree / 分支 / 队列报告与analysis路径：
每包：优先级、常规研究可派/合批复核可派/短尾待合并/条件模板/待消歧/缺材料、
      包ID与精确定位、候选名/认领建议、完整接口问题、已有覆盖/真实差集、
      原件/基线、必要VA/对象与证据绝对路径、起止/依赖/排除项、验收及最小派发文本、
      组成阶段/分别估时/近期可比实测/置信度、独占输出建议。
完成通知输入：认领ID、结论、产物/commit、开始/结束/墙钟、等待/中断、实际token（cached单列）、
              未闭边/新种子、当前执行席位及已从队列取走的包。
收到通知后：更新覆盖/依赖和优先级，按实际差集动态合并/拆分下一包，补足目标可派数量。

限制：静态范围不变；不把预调研当已验，不深挖公共库/无种子边，不复用旧上下文跨域换题。
```

## 专职整合派发模板

```text
新代理名：task_integration_两位递增序号；fork_turns: "none"；本整合批次最小上下文。
职责：实际管理主树及认领表，处理交付队列、范围/引用检查、合并、转存核对和清理。
接管确认：主树绝对路径/分支/HEAD、暂存/未暂存/未跟踪和ignored保留事项、
          唯一认领表、运行任务、交付SHA/报告定位/技术验收状态、阻塞和优先顺序。
单写入：确认交接后你独占主树及Git写操作，主窗口只传范围决策/登记请求。
        回传认领行和管理基线供主窗口派发；其他聊天写入须协调交接。
授权：在交接范围内按精确路径本地登记、提交、合并、转存和清理，无需逐项再批准。
      不推送，不改ROM/生产配置/分析器，不夹带或撤销他人改动，不派下级代理。
处理：交付立即入队；核范围/引用及技术非作者状态，保留祖先关系合并并记录交付/整合SHA。
      技术争议回主窗口或非作者复核，先合并作者成果仍标待复核。
转存：确认任务停止，列全文件；ignored复制至主树原相对路径，逐文件核SHA或字节及忽略状态。
      同名异内容不覆盖；核对后移除源副本。应入库未提交成果先补交并合并。
清理：全部commit合并、tracked/untracked干净、ignored无遗留，核实解析后绝对路径在任务根内，
      再无force移除worktree并branch -d；不reset/clean/强删，受阻保留现场并报具体步骤。
状态：运行/停止/中断；作者待复核/补修/限定接受/未决；待合并/待转存/待清理/已清理分列。
交付：整合记录commit、交付/整合SHA、逐文件转存核对、清理结果、待办/阻塞及交接基线。
生命周期：下一批先保存并交接，再换独立上下文；角色常设不等于跨题无限复用上下文。
```

## 研究任务派发模板

```text
新代理名：领域_research_两位序号；既有名称保留，同题修正不更名。
认领ID / 接口或独立阶段：
目标及业务用途：
原件身份引用 / 研究基线 / 主仓库绝对路径：
已恢复结论 / 既有复核 / 本次精确差集：
必要入口、对象、callsite/callback / 证据绝对路径与JSON pointer：
起止事件 / 允许的有限依赖 / 相交认领与分界 / 排除项：
开源替代判断：选用候选与API；若必须研究原内部，列具体理由和停止条件。
验收：输入输出、状态、错误/超时、取消/关闭、持有/归还；阶段交付列剩余共享合同。
组成阶段与分别估时 / 类比本批实测 / 已定位证据及未知依赖 / 置信度：
常规研究准入：完整可用阶段＋据近期实测预测20–40分钟真实未闭工作量。
实际预计墙钟及依据：___；已扣除旧覆盖/充分定位/现成工具/公共API止边，不能抄目标预算。
短于20分钟的同接口增量先合并，只有短差集就标短项并入既有任务/复核，不独立再开完整链。
独占worktree / 分支 / 报告与analysis输出：
本地提交授权：本次派发即授权在上述独占分支按精确路径提交本任务报告、必要合同/清单和复验源码，无需另行申请；不授权推送。
上下文：新建代理，fork_turns: "none"；仅提供本任务最小交接包。
协作：并非独自工作，不撤销他人修改；只修改独占文件，不写共享认领表。
限制：只做已授权静态研究；不自行派生代理/接后继/推送或扩到排除范围；中间产物不强制加入Git。
交付：先本地提交，再回报分支、启动基线、commit SHA、工作树状态及待转存中间产物清单；交整合席入队。
收尾：整合席验收合并，将中间产物转存到主树相同相对路径，逐文件核对及确认忽略后移除源副本；确认停止、任务树干净、ignored无遗留、commit全合并，再无force清理worktree及用branch -d删除分支。
回报：接口/阶段闭合或部分状态、可用结论、产物路径、实际检查、精确断边；
      估计/实际墙钟时间及等待/中断，可获得的token用量（不可得须注明）。
计时：首个工具调用记录UTC开始，技术冻结/提交完成/停止分别记录；缺完整起点只报观察区间。
到预算仍未闭：保存已证事实、阻塞/新种子与剩余估算，回管理窗口决定后继。
```

## 合并复核派发模板

```text
新代理名：领域_review_两位序号；同领域/类型序号递增，列全部对应认领ID。
复核批次 / 原认领ID集合 / 作者列表：
复核者对整批均为非作者；新建代理，fork_turns: "none"。
接口摘要 / 阶段交接合同 / 本批差集 / 必要已验前提：
各差集报告与证据绝对路径、JSON pointer / 独占复核输出：
独占worktree / 分支 / 启动基线：
本地提交授权：本次派发即授权在独占分支提交复核报告、必要合同/清单和复验源码，不授权推送。
交付与收尾：交付commit SHA及待转存中间产物清单，交整合席按统一流程第7节验收合并、转存核对及清理；未启用整合席时由主窗口兼任。
接口验收表：正常输入到结果、对象身份、ABI/宽度、状态、所有权、错误/超时/取消/关闭。
按本批类似差集实测单独预测墙钟与置信度（可以6–10分钟）；不统一填30分钟，不计作半小时研究包。
大批参考20–40分钟，过大按接口或独立阶段分批，不按字段拆复核。
只复核本批必要差集；不重做整库/全历史，不用管理整合代替技术验收。
逐项接受/纠正/未决；阶段已验与完整接口闭合分列，关键断边不得批量盖过。
修正后仅复查必要差集；记录实际时长、等待/中断及可获得的token用量。
协作、独占范围和静态限制与原研究一致；不改作者成果或共享认领表。
```
