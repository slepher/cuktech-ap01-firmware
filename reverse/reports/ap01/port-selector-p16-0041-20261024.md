## 真正新增

### 真实四入口建立两个请求选择域的身份桥

`0xa00f61e6..61fc`：event.word0→W，`S=load32(W+0x10)`→s1。根列表正常确认分派在 `6bf8..6c40` 要求当前页面 byte(S+2)=0x0d，读取选择 byte(S+1)→s5；其分支把旧页面0x0d保留在s6、详情页0x0e保留在s7。下表是实际赋值，而非通过数值差推定。

| 根选择 u8 S+1 | 同入口 getter-view `3b36(dst,k)` | `S+3` | `S+4` writer | `S+2` | `S+7` writer | 请求零基 index |
| --- | --- | --- | --- | --- | --- | --- |
| 0x18 | `6e48` k=1 | 0x0d | `6e5a`=0x18 | 0x0e | `6e62`=1 | 0 |
| 0x19 | `6ef4` k=2 | 0x0d | `6f06`=0x19 | 0x0e | `6f0e`=2 | 1 |

| 0x1b | `704c` k=4 | 0x0d | `705e`=0x1b | 0x0e | `7066`=4 | 3 |

各入口先调用 getter-view `0xa00f3b36(dst,k)` 再依次写 S+1=8、S+3=旧页面、S+4=旧选择、S+2=详情页、S+7=k。`3b44..3b50` 明确计算 `u8(k−1)` 并 call `0xa00a53c0`；该函数借用项，不返回/存储 item 指针到 S。S+4 是“返回根列表时恢复的选择”，S+7 是当前详情 selector；根选择/snapshot索引的桥来自同一个入口中的真实常量与 getter 调用。

详情开 switch 时 `79d4..79fe` 改 S+2/S+1 进入0x15/0x11；开 safe 时 `7144..7158` 经页面capability byte非零门后改为0x16/0x14。上述开页片段均保留 S+4/+7。safe 动作原P14窗口再从 S+4 得索引，switch 从 S+7 得索引。因此对这四条正常入口，两种请求都指向同一个 **UiIFace 数组项0..3**。S+3/+4还用于详情返回 `719e..71aa` 恢复页面/选择的旧合同，不是独立物理端口命名。

P14的 safe 算术允许 S+4=0x1c→index4，并不证明本题四入口中存在第五个详情构造器；本轮未建立 S+4=0x1c / S+7=5 的同源 writer，不能把算术接受域当已达正常UI域。

### callback descriptor 的准确匹配规则

callback `0xa00f5288(W,I)` 的 `531e` 读取同 W+0x10 的 S，`534a`读取 I+0x24 word，随后5350提取类型bit5..4。标准指令 `5356..5370` 建立以下 selector（分析伪代码，非原源码）：

```c
uint32_t d = load_u32(I + 0x24);
unsigned type = (d >> 4) & 3;
unsigned selector = 0;
if (type == 1) selector = 4;
else if (type == 2) selector = 5;
else if (type == 0 && (d & 15) <= 2)
    selector = ((d & 15) + 1) & 15;
```

type3、type0且nibble>2保持selector0；type1/2忽略低nibble。safe反馈 `5b0a..5b12`、switch反馈 `5b6c..5b74`均比较 **u8(S+7)==selector**，再沿P14的mask/页面非空门更新。这里没有比较I+0x13，也没有request ID、提交时间或请求值与遥测值的比较。

### 同 selector 不足以证明同数组项：可用合同及停止边界

初始化 `0xa00a8aca..8b26` 对数组序号 i：I=`array+i*0x1a8`，从 desc[i+0x17] 依次复制bit6、低4位、bit4..5到 **I+0x24 byte**，并写 **u8(I+0x13)=i**。这是两份不同意义的数据；本题没有观察到用 i 构造I+0x24或将描述符校验成固定顺序。

所以原 callback 的已证匹配条件只是descriptor选择号匹配。重建程序要让请求与**同项最新观测**相连，可用下面的显式合同；这是基于已证布局的接入策略，不冒充原 ROM 的额外检查：

1. 在上述真实入口存应用自有 `{array_index=k−1, ui_selector=k}`；switch/safe提交均使用该 array_index。保留原value与cmd63门控，不复用远端内部子端口号。
2. 同步 callback 内复制 `{u8 I+0x13, descriptor I+0x24, mask, safe u8 I+0xc, switch显示源 u16 I+0xa}`，回调外不持有I/资源/mask指针。
3. 仅在 copied.array_index==请求array_index **且** 上述descriptor映射==ui_selector时，把它当同项观测；不满足则保留不匹配/未知，不能只按selector路由成同项。
4. 即使双条件成立，也只能报告同项遥测；P14保留的发送接纳、底座执行、响应年龄和因果确认仍未知。断连/重建应丢弃旧项指针；跨快照代际关联需应用自有代际策略，本文不认证ROM有generation字段。

这一合同允许实现者在描述符顺序未认证前安全区分索引和显示选择，并指出真实ROM过滤比“数组索引相同”的条件弱。未做设备观测或异常输入实验，不据此宣称原固件存在缺陷。
