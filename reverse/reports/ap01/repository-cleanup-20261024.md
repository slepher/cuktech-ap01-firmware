规则见 [分析材料保留说明](../../analysis/README.md)。保留的复验脚本没有被改成忽略缺失输入或假定成功；需要旧 Evidence 的脚本仍需准备本地归档输入。历史路径、提交号及哈希按冻结证据解释。

清理前已在同级 `cuktech-ap01-firmware-archive-20261024/` 保存并验证完整 Git bundle、当前跟踪及未忽略文件快照、逐文件 SHA256、全部引用与工作树状态。导出移出时逐项核对哈希；ROM、工具/固件源码和 SDK 与快照逐文件核对未改变。

现场实际仍有 59 个关联工作树，均无未提交修改。其提交因 cherry-pick 不构成主分支祖先，但各任务相对共同基线新增/修改的文件与主目录逐文件一致；核对后归档忽略输出并移除工作树和对应任务分支。路径、旧提交、等价性和处理结果留在仓库外 `worktree-cleanup-results.json`。当前只保留主工作树。

使用 git-filter-repo 2.47.0，按同一保留规则过滤全部本地引用的完整历史，再清除旧 reflog 和不可达对象；没有创建保留旧历史的仓库内备份引用。旧历史仅在仓库外 bundle 中保留。远端没有推送；本地历史改写不等于 GitHub 远端已清除。

本轮验证以归档完整性、源码/ROM 保全、保留 JSON 可解析、忽略规则、历史路径及旧对象不可达检查为准，没有为仓库清理重跑固件构建、设备操作或历史模拟。
