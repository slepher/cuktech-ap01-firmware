# 0041 D17：PWM lower 本地来源认证边界

基线 `d493236b8802ec310e9433e8761fb1eb40e2b822`，独占树 `re0041-d17`，分支 `codex/re-0041-d17`。按 reverse-engineer-anything 技能，仅将 D15/D16 已闭的 `a0136762` 正常 start 与两个已知本地候选作源级比对。结论：**NuttX 12.10.0 的 BL602 lower 不是该合同的等价实现；SDK PWM v2 在寄存器操作层局部相符，但没有提供 ROM 的频率搜索及 duty 居中算法。精确 lower 来源、版本与厂商适配仍未认证。** 新增 ROM 功能 0，新增开源整库排除 0。

## 真正新增：来源适用边界

新增的是 BL602 候选与 ROM 的三个明确不等价点（频率搜索、duty 公式、寄存器/对象布局），以及 v2 threshold/positive_start 的局部对应与 lower 计算层之间的准确断边。D15 已经知道 v2 init 不含分频/duty算法；该点和字段对应本轮只是复核，不计新增。

事实为上述候选文本/行号及 D15/D16 已核 ROM 指令合同。分析推断为 ROM 所用寄存器族与 SDK v2 局部相容，且尚需一个 NuttX 风格 lower/计算适配层。**不能把该未匹配层直接命名为厂商新增或修改**：可能来自不同上游版本、不同芯片驱动或私有适配，现证据不作选择。没有匹配原始 lower 文件、版本和构建条件，故没有源码认证或整库排除。

[source_check.py](../../analysis/pwm-source-auth-d17-0041-20261024/source_check.py) 仅重读三份 NuttX 必要文件与两份 SDK 文件，执行29项源文本锚点检查；[source-check.json](../../analysis/pwm-source-auth-d17-0041-20261024/source-check.json) 保留标签、精确路径和行号，不复制源函数或整库清单。字面量未命中仅适用于所列单文件，不是全库/任意改名算法负证明。脚本执行通过，人工对照上表必要源码行；无固件、SIM、构建、历史回放、模型、设备或网络执行，没有打开共享 REA 数据库、改生产代码/ROM/配置/模型。
