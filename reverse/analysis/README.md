# 分析材料保留规则

Git 保留研究结论、语义合同、必要资源清单、来源摘要、ROM 身份及复验源码。逐指令 JSON、整段反汇编、REA 完整导出、重复指令窗口、全量函数关系账本、运行日志和构建输出不入库；`.gitignore` 默认排除分析生成物，只放行源码和明确列出的合同/清单。

2026-10-24 清理前的完整历史与工作目录快照保存在仓库外的 `D:/Documents/PlatformIO/Projects/cuktech-ap01-firmware-archive-20261024/`：

- `before-cleanup.bundle`：历史重写前全部 Git 引用，可用于隔离恢复。
- `working-tree-snapshot.zip`：当时全部跟踪文件和未忽略的新文件，保留原相对路径。

- `cleanup-plan.json`：本次移出文件清单。
- `exports/`：从主工作目录移出的生成物，保留原相对路径。

历史报告中的原路径、旧提交号、Evidence ID 和哈希是冻结证据，不因清理改写。报告中指向已移出 JSON/反汇编的旧链接表示本地归档材料，不表示当前 Git 检出含有该文件；可在上述 ZIP 或 `exports/` 中按原路径查找。旧提交号需在仓库外 bundle 的隔离副本中使用。

复验脚本保留原有输入校验。依赖历史 Evidence 的脚本需要先从归档准备材料，不能把缺失材料解释为检查通过，也不应为了运行脚本重新提交导出。直接读取 ROM 的复验仍可按各脚本原有约束使用。

`whole-rom-summary-0041.json` 仅保存历史首轮枚举摘要，不含逐函数记录或指令。它不是完整覆盖认证；语义合同仍保留各自的未知项和来源边界。
