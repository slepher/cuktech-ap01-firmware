# 0055／0.1.2 本地维护凭据菜单

无 App 基版和 ABI 3 加载平台均提供设备码菜单，维护凭据由设备生成，不依赖业务 App 或 GitHub 发布密钥。

## 使用

1. 在设备设置中打开“设备码”页面，读取八位设备码。
2. 使用当前设备码进行维护通道认证；维护服务监听端口为 18080。
3. 选择“重新生成”轮换凭据，确认菜单显示成功后使用新码。
4. 选择“返回主菜单”退出。

若页面显示“读取失败”或“结果待确认”，应重新读取有效凭据，不把未确认的码当作成功结果。

## 存储与接口

`native_device_code.cpp` 管理 `/data/ap01_ui.device_code`，通过临时文件 `/data/ap01_ui.device_code.new`、同步、读回与重命名确认持久化结果。凭据格式为 DVC1，码值为八位数字。

`native_device_code_menu.cpp` 与 `native_device_code_hooks.cpp` 负责设置菜单接入；`native_maintenance.*` 负责维护鉴权与限流。菜单展示和服务鉴权使用设备端持久化的有效凭据。

诊断客户端使用方法见 [固件模块](README.md#平台诊断版本协议)。不要将设备码、登录缓存或凭据文件提交到仓库。菜单、凭据持久化和掉电行为仍需实机验收。
