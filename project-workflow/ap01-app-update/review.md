# 当前设计审阅

业务恢复自审：平台许可到业务初始化必须经现有 businessLock，不能让 UI 执行 VFS 或在每个 tick 重建 context。begin 改为完成后才发布 writesEnabled；失败默认只读，syncWritePermission 锁存恢复失败，Runtime health 上报 Failed。宿主真实 Bundle 测试覆盖恢复/撤权/幂等与失败；首次故障注入按变更次数定位误中了 open 而非 write，改为明确拒绝写入后通过。QEMU 验证 worker 确实读取 C 表许可，包含无 Bundle 首次初始化和 mkdir 失败不重试；未宣称已实现持久批准。

集合写许可自审：每 App 的局部写标志不足以原子切换整集，改为共享准入与在途操作计数；仅变更操作持有计数，文件服务原锁仍保护句柄。撤权失败返回值明确表示尚未排空，不能错误解读为旧策略仍有效。序贯一致原子顺序保证撤权返回已排空后，迟到的准入不会执行写入；开放只允许无在途操作。阻塞写与另一 App 撤权的测试验证该边界。实际 Bundle/配对只读回归通过，但持久授权→业务 begin(false) 及维护直接 I/O 协调尚未接线。

工作线程健康自审：新增三个 uint32 原子字段（12 B 字段存储，无持久格式变化），只影响文件 App 分支；健康先等待两个 worker 启动，再检查最近循环进度。未以启动成功、线程数量或累计计数代替活性。真实 RV32 故障注入每次只冻结一条线程，并断言另一 App 仍健康；恢复后保留平台故障记录。复核发现时间采样先于并发心跳可造成无符号下溢，已在 App 和平台观察器处理，并补未来时间戳回归。观察期限暂非硬件最大延迟证明，渲染/ROM I/O 上界需另行验证。

D2 监督自审：避免跨线程调用加载器的非原子 dispatching/ready 状态。UI 采样，监督线程只读取原子快照；并发快照测试验证时间戳与健康数组来自同次发布。HTTP 读取平台状态，不执行 App health/online；维护心跳在发布 listening 前初始化，避免首次监听被误判陈旧。故障锁存不会被并发正常观察覆盖。窗口正常销毁与 UI 停滞分开，自动重启暂不触发。仍缺 App 自身全部关键工作线程的活性证据，以及 D3 有界重启/失败回执，监督任务不勾选完成。

D2 文件入口自审：避免沿用 D1 在 UI 读取 VFS 的方式，增加有界工作线程暂存并显式扣减 RAM 预算。包文件只由验证后的摘要派生路径，平台包目录不与任意 App ID 私有根重叠；所有成功打开文件均关闭，关闭失败不发布快照。缺包/损坏等在执行预留前拒绝；执行 backend 拒绝后维护和原厂导航仍存活。测试在 stage 后清空文件映射并禁止 UI 调用 I/O，真实双包 QEMU 也验证同一文件组合。固定 schema 1/固定 Manifest 是尚未接事务选择的明确限制；生产执行 backend 继续拒绝，不能部署。

D2 真实双包自审：打包器增加 ID/版本/预算/能力参数，旧默认值保持。peer 通过 C 表调用，health 跨线程字段使用原子。集合 guest 复用单包分配器、调度器和 APX2 加载器，新增 Manifest/peer 输入并由 runner 核验摘要。两基址实际执行、三任务、页面切换和两包窗口重建通过；peer 重复构建一致。`real_abi_v3_collection_executed` 不意味着硬件或完整 ROM 启动已验证，生产 Manifest 文件入口和持续监督仍待完成。

D2 集合组合自审：常驻集合所有者复用现有 parser/预检/加载器及共享平台，包存储回调保留原上下文；每个启动条目创建独立授权上下文，并在失败后保留。组合 ASan/UBSan 验证窗口重建和第二包失败；真实单包 QEMU 双基址回归通过。首次测试错误地在 attach 前读取未注册的 app_id，测试进程 ASan 终止；修正断言顺序及删除事件 target 后通过。生产 Manifest 入口、真实双包执行仍未验收，不由宿主替身或单包 QEMU 推断完成。
